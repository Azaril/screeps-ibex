# docs/design/

Architecture Decision Records (ADRs) for the rewrite's pillars, plus design notes.

- New ADRs: copy `adr-template.md`, number sequentially (`NNNN-title.md`).
- **Status lifecycle:** `Draft` → `Decided` → `Superseded by NNNN` / `Withdrawn` (non-ADR documents
  use `Research note` / `Results note` / `Catalog` / `Scoping note`). The status describes the
  **design's** maturity only — there is deliberately no "Implemented".
- **An ADR never states implementation progress.** Whether something is built, deployed, or open
  lives in [`../execution/implementation-tracker.md`](../execution/implementation-tracker.md) (§5–§6);
  in-flight work's resume state lives in [`../implementation/`](../implementation/). This split is
  deliberate (2026-08-22): the previous combined header drifted on 29 of 56 ADRs. Do not add status
  columns or progress claims here or in any ADR — that reintroduces the drift class.
